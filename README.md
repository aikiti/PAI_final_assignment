# Physical AI 応用1 最終課題

講座「Physical AI 応用1」最終課題で使ったコードです。題材は、参加中の PARC2026(東京大学 松尾・岩澤研究室主催)本選の Track3(逆転タスク)です。
シミュレータ LIBERO 上で、ロボットアームに「棚から本を取り出し、机の上の決められた場所に置く」作業を VLA モデル π0.5 で実行させました。
課題の内容と結果は、提出したレポートと動画にまとめています。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `training/` | π0.5 の追加学習のラッパー(`pi05_train_wrapper.py`)、学習データの抽出(`draw_manifest_sampler.py`)、学習の監査(`train_audit.py`)、重みの書き出し(`pi05_export_bf16.py`)など |
| `evaluation/` | 手元(Mac)での評価。配布キットの評価ループをそのまま呼び、結果を 1 回ずつ記録する(`b3_panel/run_panel.py` など) |
| `policy_server/` | 推論サーバの起動時の乱数の種を固定する差し込み(`seed_patch_policy_server.py`)と、Mac での起動(`serve_qself_mps.py`) |
| `video/` | 提出物(録画・動画の組み立て・このフォルダの作成・レポートの PDF 化)を作る台本 |

## 含めていないもの

- Track3 の道具(人手デモの記録ツール、逆転タスクの自動生成、人手デモを混ぜた学習と評価の台本): PARC2026 本選の期間中(11/24 まで)のため、公開を控えた
- 推論サーバ本体(`policy_server.py`): PARC2026 本選の配布リポジトリ(招待制)の例をもとに改変したもののため、公開リポジトリには含めていない
- モデルの重み(1 本約 7 GB)、学習データ、人手デモの記録データ
- コンペの配布キット(評価ハーネス)、外部ライブラリ(LeRobot・LIBERO・robosuite・MuJoCo など)

## 注意

- 作成者の環境(macOS)の絶対パスは、公開にあたりユーザー名の部分を `USERNAME` に置き換えた。そのままでは動かず、配布キットと外部ライブラリの導入が必要
- 学習はコンペで配布された GPU 環境、評価と動画の作成は Mac(Apple M3 Max)で行った
